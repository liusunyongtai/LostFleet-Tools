# SSJNL · 双头机械爪角色骨骼动画

目标 **Spine PRO 4.3.23**，24 根可编辑骨骼、11 个加权网格。保留提供的十一张原始透明 PNG、PS 初始摆位和图层顺序，根骨骼移至脚下；没有新增或补画被遮挡的身体、手指或头部。

## 本地 Spine 导入

1. 完整解压 ZIP，保留 JSON 与 `images/` 的相对目录。
2. 在 Spine PRO 4.3.23 中选择“导入数据”，选择 **ssjnl-4.3.json**，缩放设为 **1**。
3. 若图片显示丢失，将骨骼图片路径指向解压目录的 `images/`。
4. 进入动画模式选择下列动作，再“另存为”自己的 `.spine` 工程。游戏所需的 atlas、纹理和运行时数据请使用本地 Spine 导出。

本包提供可编辑 Spine JSON，不包含原生 `.spine` 文件或已打包图集。`source/photoshop.json` 仅是原始 PS 摆位备份，不是动画成品。

| 动作名 | 时长 | 播放方式 | 动作设计 |
|---|---:|---|---|
| stand | 2.4 秒 | 循环 | 呼吸起伏、双头错相轻摆、背包和腰包跟随、锁链轻摆 |
| dead | 1.6 秒 | 单次，保持末帧 | 屈膝失力、双头侧倒、锁链收至身旁、副头和后脚落地、回弹稳定 |
| hit | 0.5 秒 | 单次 | 身体后震、双头延迟、手臂和装备惯性摆动、回弹复位 |
| attack_1 | 1.2 秒 | 单次 | 右爪后收蓄力、向左前方伸出抓击、回弹收势 |
| attack_2 | 1.4 秒 | 单次 | 右爪举过头部、停顿蓄力、斜向前下方劈抓、身体下压与回弹 |
| move | 1.0 秒 | 循环 | 双腿交替、重心起伏、反向摆臂、背包和锁链延迟跟随，根骨骼保持原地 |

本次未指定两个攻击的具体招式，因此根据现有机械爪素材，分别设计成前伸抓击与抬爪斜劈。角色主要朝画面左侧，两个攻击均使用原 `youshoubi` 右爪图层，左手只辅助平衡。

## 图层与跟随

- 主头、副头分别绑定骨骼，使用不同的摆动相位和回弹时机。
- `yanjing` 跟随主头，保持原来的眼部位置，不会在头部转动时独立漂移。
- 机械爪主体保持原有张爪形状，由肩、前臂与腕部驱动；没有制作新的手指闭合图层。金属手指区域采用刚性绑定，变形主要集中在上部软组织与关节连接段。
- 背包与腰包保持刚性形状，做少量惯性摆动；锁链整片绑定在腰侧固定点，小幅摆动，不做未经验证的逐链节物理模拟。
- 两条腿使用加权网格弯曲，脚部补偿保持靴子姿态。移动是原地循环，实际游戏水平位移由代码控制。
- 攻击期间右爪临时移至头部前方绘制，保证抓击轮廓可见；收势时恢复原始图层顺序。

## 游戏事件

- `attack_1` 在 **0.5 秒（30fps 第 15 帧）**发送 `claw_hit`。
- `attack_2` 在 **19/30 秒，约 0.633 秒（第 19 帧）**发送 `slash_hit`。
- 两个事件的字符串均为 `claw_tip`，可作为机械爪末端的命中位置参考。真实碰撞、伤害与目标距离由游戏逻辑处理。
- `hit` 在 0.1 秒发送 `impact`。
- `dead` 在 1.4 秒发送 `death_end`，到 1.6 秒保持稳定末帧。
- `move` 在 0.5 秒和 1.0 秒发送 `footstep`，字符串区分 `back_leg` / `front_leg`。

待机和移动可循环；攻击、受击和死亡应单次播放。普通攻击动图和所有手机动图为了比较会循环演示。

## 预览与复现

直接打开 `preview.html` 查看六组普通尺寸和约 128px 角色高度的 GIF，以及关键姿势和骨骼图。预览来自独立软件渲染器，不是 Spine 桌面截图。

完整源码仓库包含 `tools/build_ssjnl_spine.py`、`rig-config.json` 和测试。可调整枢轴、权重或动作控制点后运行：

```sh
python tools/build_ssjnl_spine.py
SPINE_CORE_MODULE=/path/to/@esotericsoftware/spine-core/dist/index.js node tests/validate_ssjnl43.mjs
python -m unittest discover -s tests -v
```

独立 ZIP 可以直接导入 Spine，无须运行生成器。生成器复用现有 Pillow、OpenCV、NumPy 工具，没有修改角色拆分网页、PNG 导出或 ZIP API。
