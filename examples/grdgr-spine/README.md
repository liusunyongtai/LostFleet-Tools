# GRDGR · 感染工人挥拳动画

目标 **Spine PRO 4.3.23**。包含 27 根可编辑骨骼、5 个加权网格，以及你提供的五张原始透明 PNG。原图字节、PS 的层顺序和初始摆位均保留，根骨骼原点移至脚下。身体与双腿仍使用一张连续网格，没有切腿或补画遮挡部位。

## 在本地 Spine 导入

1. 完整解压 ZIP，保留 JSON 与 `images/` 的相对目录。
2. 在 Spine PRO 4.3.23 中选择“导入数据”，选择 **grdgr-4.3.json**，缩放设为 **1**。
3. 如果图片丢失，将骨骼的图片路径指向包内 `images/`。
4. 进入动画模式选择下面的动作；导入后“另存为”你自己的 `.spine` 项目。游戏所需图集、纹理与运行时数据，请使用本地 Spine 的导出功能生成。

`source/photoshop.json` 是原始摆位备份，不是动画成品。本包提供可编辑 JSON，不包含原生 `.spine` 文件或已打包的 atlas。

| 动作名 | 时长 | 播放方式 | 动作设计 |
|---|---:|---|---|
| stand | 2.4 秒 | 循环 | 躯干呼吸、大头轻摆、手臂和触须延迟跟随 |
| dead | 1.6 秒 | 单次，保持末帧 | 屈膝失衡、侧倒落地、回弹后稳定 |
| hit | 0.5 秒 | 单次 | 身体后震、头部滞后、回弹复位 |
| attack | 1.0 秒 | 单次 | 收拳后仰蓄力、前景手向左挥拳、躯干跟进、回弹收势 |
| move | 1.0 秒 | 循环 | 双腿交替、反向摆臂、重心起伏，根骨骼保持原地 |

出拳使用原 `zuoshoubi` 图层，保留原手套造型，由上臂、前臂和手腕驱动；出拳时头部后收，颈部触须让开拳路，另一只手反向平衡。快速出拳段配合轻微手臂拉伸，突出手机小尺寸下的轮廓变化。头部三组触须和独立颈部触须有延迟摆动。没有生成新的拳头、身体或隐藏部位贴图。

## 游戏事件和位移

- `attack` 在 **0.4 秒**触发 `punch_hit`；`punch_point` 是前景拳头参考骨骼。请由游戏逻辑进行碰撞检测与伤害结算。
- `hit` 在 0.1 秒触发 `impact`。
- `dead` 在 1.4 秒触发 `death_end`，到 1.6 秒保持最终倒地姿势。
- `move` 每半周期触发 `footstep`，事件字符串区分 `back_leg` / `front_leg`。
- 移动是原地循环，角色实际水平位移由游戏代码控制。待机和移动可以循环；死亡、受击和攻击应单次播放。

## 预览、编辑与复现

打开包内 `preview.html` 可查看普通尺寸与约 128px 角色高度的五组 GIF、关键姿势和骨骼图。手机 GIF 为便于比较均循环演示。预览由独立软件渲染器生成，不是 Spine 桌面截图。

在完整源码仓库中，可以修改 `rig-config.json` 或 `tools/build_grdgr_spine.py` 调整枢轴、权重和动画节奏，再运行：

```sh
python tools/build_grdgr_spine.py
SPINE_CORE_MODULE=/path/to/@esotericsoftware/spine-core/dist/index.js node tests/validate_grdgr43.mjs
python -m unittest discover -s tests -v
```

独立 ZIP 直接导入 Spine 即可，不需要运行生成器。生成器使用仓库中已有的 Pillow、OpenCV、NumPy 网格渲染工具。

## 验证范围

官方 `@esotericsoftware/spine-core 4.3.13` 已用于读取目标版本 4.3.23 数据，并以 **60Hz 检查五动作共 395 个姿势**的骨骼与全部网格顶点。抽样网格顶点和骨骼矩阵与独立预览数学计算比较，记录在 `runtime-validation.json`。

自动化测试还检查五个动作名、五张 PNG 哈希和 Alpha、PS 初始摆位、权重归一、循环衔接、原地根骨骼、双腿路径、挥拳方向及拳头领先头部、动作复位、网格连通、旋转跳变和倒地稳定性。

**未运行桌面 Spine 4.3.23，不能宣称桌面导入已实测。** 验证记录明确包含 `desktopEditorTested: false`；请在你的本地 PRO 软件中导入后确认，并可继续编辑骨骼、网格和时间轴。
