# SYCS 深渊触手 · Spine PRO 4.3.23

基于上传的 `sycs.json` 和 17 张透明 PNG 制作五个动作：`stand`、`dead`、`hit`、`move`、`attack`。身体呼吸摇摆，长触手分节蠕动，头顶玻璃罐里新增 8 个由下向上循环的透明气泡。攻击包含后收蓄力、触手前抽、气流拖尾和回弹。

保留原始图片字节、透明度、文件名和设置姿势坐标，不补绘未知的遮挡部位。新增气泡与气流是程序生成的透明特效。

## 在本地 Spine 导入

1. 完整解压 ZIP，保持 JSON 与 `images/` 相对目录。
2. 在 **Spine PRO 4.3.23** 选择“导入数据”，导入根目录 **`sycs-4.3.json`**，缩放填写 **1**，图片路径为 `./images/`。
3. 保存成自己的 `.spine` 工程。本包是可编辑 JSON，不伪造二进制 `.spine` 文件。
4. 动画模式中，`stand`、`move` 打开循环；`attack`、`hit` 播放一次，`dead` 播放一次并保持末帧。

使用 Professional 的加权网格功能。共 **42 根骨骼、28 个插槽**，其中包含新增气泡、气流和用于保护攻击触手嘴部形状的附件。原始 `sehnti`、`youchusou_02` 等文件名保持不变。

| 动作 | 时长 | 内容 |
| --- | --- | --- |
| `stand` | 3.2 秒 | 身体呼吸摇摆，多组触手错相蠕动，罐子与软管延迟跟随；气泡完成两轮上浮 |
| `move` | 1.6 秒 | 原地缓慢挪动，身体稍前倾，触手和脚边卷须交替蠕动；气泡完成一轮上浮 |
| `attack` | 1.6 秒 | 前景长触手后收蓄力、向左前方抽打、快速气流拖尾、回弹并复位 |
| `hit` | 0.5 秒 | 身体后震，罐子和触手延迟摆动，随后恢复 |
| `dead` | 1.6 秒 | 侧倒、触手收拢、落地回弹，气泡停止并淡出；1.4 秒后保持静止 |

## 气泡与玻璃罐

8 个气泡使用普通透明 region 附件及骨骼关键帧，路径固定在罐子的局部坐标中。罐子旋转、摇晃时，气泡随罐子一起运动，仍留在玻璃范围内。周期为 **1.6 秒**，上方淡出、底部淡入，回到底部的跳转发生在不可见阶段。

罐子本身使用刚性 region，保留完整原画；新增气泡叠加在玻璃内部，不改变原来画在罐子里的生物、眼睛和高光。没有外部粒子系统或脚本依赖。受击时气泡保持局部位置并随罐子震动；死亡时停止并淡出。

`previews/jar-bubbles.gif` 提供完整 3.2 秒待机循环的罐内近景，方便检查上浮与淡出。

## 抽打与游戏接入

素材整体朝左。攻击使用前景长触手（原图 `zuochushou_01`）。触手链先求解可读的关键姿势，再对世界角度平滑插值，避免回收时肘部切换导致的翻转。触手末端嘴部使用同一张原图的独立 UV 区域，保留眼睛和牙齿的形状；没有另画或改写原 PNG。

**0.6 秒**发送 `whip_hit` 事件，字符串为 **`strike_tip`**，可作为游戏中的攻击参考点。伤害、碰撞范围和目标判定由游戏控制。气流在约 **0.5–0.7 秒**显示并淡出，沿实际抽打轨迹布置，是单一 UV 区域的透明加法网格。运行时应支持 Spine additive 混合，并按自己导出的图集配置 PMA。

`stand`、`move`、`attack` 的根节点始终为 **0,0**。`move` 是原地循环，实际移动速度与路径由游戏控制。建议在待机、移动和攻击之间使用约 0.12–0.18 秒混合。`hit` 有 0.1 秒的 `impact` 事件，`dead` 有 1.4 秒的 `death_end` 事件。

本包不是已经导出的游戏 atlas。请在本机 Spine 导入、保存工程，再按目标运行库导出 JSON/二进制和图集。

## 文件与预览

- `preview.html`：五动作普通尺寸和手机尺寸预览、气泡近景、关键帧和绑骨图。
- `previews/*.gif`：独立软件渲染，**不是 Spine 桌面截图**；手机预览角色约 128px 高，死亡等姿态的屏幕轮廓会变化。
- `images/*.png`：17 张原始角色图；SHA256 在 `source/image-sha256.json`。
- `images/fx/bubble.png`、`whip_air.png`：新增透明气泡与气流。
- `source/sycs.json`：原始上传 JSON；`source/photoshop.json` 仅规范化图片路径。
- `rig-config.json`：关节、触手链、玻璃范围和气泡路径设置。
- `runtime-validation.json`：官方运行库逐帧检查记录。
- `editor-topology-validation.json`：编辑器相关的 UV、三角形、边界与 edges 检查记录。

普通浏览器可打开 `preview.html`；若本机限制本地文件资源，在本目录执行 `python -m http.server 8000`，打开 `http://127.0.0.1:8000/preview.html`。云端浏览器验证使用临时 HTTP 服务，不代表已测试本机 `file://` 或 Codex 内嵌预览。
