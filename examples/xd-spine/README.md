# XD · 悬浮锯盘机器人 / 叉形工具投掷

面向 **Spine PRO 4.3.23**：16 根可编辑骨骼，10 个网格插槽。九张原始 RGBA PNG、PS 初始坐标及图层顺序保留；没有补画隐藏部位或新增手掌。

## 本地 Spine 导入

1. 完整解压 ZIP，保留 JSON 与 `images/` 的相对目录。
2. 在 Spine PRO 4.3.23 中选择“导入数据”，导入 **xd-4.3.json**，缩放设为 **1**。
3. 如图片丢失，将骨骼的图片路径指向解压目录的 `images/`。
4. 进入动画模式选择下列动作，再“另存为”自己的 `.spine` 项目。游戏的 atlas、纹理和运行时数据请通过本地 Spine 导出。

本包提供可编辑 JSON，不包含原生 `.spine` 工程或图集。`source/photoshop.json` 仅是原始 PS 摆位备份，不是动画成品。

| 动作 | 时长 | 播放方式 | 设计 |
|---|---:|---|---|
| stand | 2.4 秒 | 循环 | 空中起伏、躯干呼吸、机械柱伸缩、手臂跟随、锯盘持续旋转 |
| dead | 1.6 秒 | 单次，保持末帧 | 悬浮失效、重心下落、关节折叠、落地回弹、锯盘减速停止 |
| hit | 0.5 秒 | 单次 | 身体后震、头部延迟、手臂甩动和回弹复位 |
| attack | 1.2 秒 | 单次 | 向右收臂蓄力、抬臂前送、向左投叉、回弹收势 |
| move | 1.2 秒 | 循环 | 身体前倾、空中上下起伏、锯盘旋转；根骨骼原地不漂移 |

锯盘使用 `disc_plane` 的固定 Y 缩放和子骨骼 `disc_spin` 的旋转，在倾斜盘面内旋转，轴心保持在原图轴承处。**这是基于二维原图的透视近似，不是三维模型**；原盘片不完全对称，外轮廓有轻微摆动。待机两圈、移动一圈，均为 300°/秒；循环首尾相接，不会把整张椭圆图片转成竖盘。死亡时盘片减速停止。

## 投掷与游戏接入

素材 `youshou.png` 是**带握柄和红色连接环的整件叉形工具**，没有独立的手掌图层。因此投出整件工具，原机械上臂保留连接关节，没有只飞出叉头，也没有凭空补画手指。

- **0.5 秒（第 15 帧，30fps）**触发 `throw_fork`。事件字符串为 `fork_flight`，指示飞叉中心的参考骨骼；`throw_point` 提供前端参考位置。
- `youshou` 插槽在出手时隐藏，演示用 `fork_flying` 插槽在同一时刻显示。出手瞬间全部网格顶点重合，保持位置、缩放和朝向连续。
- 飞叉向画面左方沿弧线运动并翻转一圈，在 0.9 秒隐藏。
- 为便于重复预览，工具在 **1.1 秒重新装备**；此切换并非手掌生长或实体回收动画。游戏可改为由武器库存和装备逻辑控制重新显示。
- 若游戏自己创建独立投射物，请隐藏演示用 `fork_flying` 插槽，在 `throw_fork` 时读取 `fork_flight` 的世界位置与旋转，用原 `images/youshou.png` 创建投射物，避免出现两个飞叉。碰撞、伤害和真实速度由游戏代码处理；包内飞行轨迹用于演示。
- `hit` 在 0.1 秒发送 `impact`，`dead` 在 1.4 秒发送 `death_end`。
- `move` 为原地悬浮循环，实际游戏位移由代码控制；不使用脚步事件。

攻击中机械臂临时移到头部前方绘制，使甩臂与叉子脱手可见。收势后恢复 PS 图层顺序。死亡、受击和攻击应单次播放；待机和移动可循环。

## 预览和复现

直接打开 `preview.html` 查看五组普通尺寸和约 128px 角色高度的 GIF，以及关键姿势和骨骼图。手机 GIF 为便于比较会循环演示。预览由独立软件渲染器生成，不是 Spine 桌面截图。

完整源码仓库包含 `tools/build_xd_spine.py`、`rig-config.json` 和测试；可修改枢轴、盘面投影系数、动作控制点或投掷时刻后重新生成：

```sh
python tools/build_xd_spine.py
SPINE_CORE_MODULE=/path/to/@esotericsoftware/spine-core/dist/index.js node tests/validate_xd43.mjs
python -m unittest discover -s tests -v
```

独立 ZIP 可直接导入 Spine，不需要运行生成器。生成器复用仓库现有 Pillow、OpenCV、NumPy 渲染工具；未更改角色拆分网页或导出 API。

## 验证范围

官方 `@esotericsoftware/spine-core 4.3.13` 读取目标 4.3.23 数据，以 **60Hz 检查五动作共 419 个姿势**，检查全部可见网格顶点，并与独立预览的骨骼矩阵、抽样网格顶点、附件显隐和绘制顺序比较。记录见 `runtime-validation.json`。

自动化测试覆盖原始 PNG 哈希与透明度、PS 原始组装、倾斜盘面旋转与轴心、悬浮不触地、移动前倾、循环衔接、原地根骨骼、投掷幅度、完整工具脱手、挥臂过程中叉子与锯盘可见像素不交叠、脱手瞬间连续、单个投射物显隐、前景绘制顺序、受击和攻击复位、倒地接地与稳定性。
