# 112 双翼飞行生物 · Spine PRO 4.3.23

根据上传的 `112.json` 与 11 张透明 PNG 制作，保留原始图片和图层顺序。新增 25 根骨骼和 11 个网格，提供五个动作：`stand`、`dead`、`hit`、`move`、`attack`。双翼、长尾与长颚使用连续加权网格，翼尖、尾尖、背鳍和颚部有延迟跟随；不补绘未知的遮挡部位。


## 本次导入修复

日志的致命错误发生在 `shenti` 网格读取阶段（`Index -2 out of bounds`）。运行库成功读取数据不足以证明桌面编辑器能重建该网格。本版为所有 11 个网格补齐显式 `edges`，将身体网格从 527 个顶点降为 325 个，保留骨骼、五个动作的曲线、原始图片和透明度。降低密度是兼容性措施，不代表 Spine 存在 512 顶点的格式限制。

包内有两种导入文件：

- **`bird112-4.3.json`**：完整加权网格修正版，保留翼尖、尾部与颚部连续形变。
- **`bird112-regions-4.3.json`**：不包含任何 mesh 的兼容版，绕开此次报错的网格解析步骤。保留五动作、振翅、收翼俯冲和原地循环，但翼尖、尾巴和颚尖的弯曲更简化；死亡高度按刚性图像单独接地。

先尝试完整修正版；若同一编辑器仍拒绝，可导入兼容版确认。两者均以缩放 **1** 导入，并保留同级 `images/`。兼容版外观差异可看 `previews/regions-comparison.gif`。**两版尚未在桌面 Spine 4.3.23 中实测，编辑器导入结果仍需本机确认。**

## 导入本地 Spine

1. 完整解压 ZIP，保持 `bird112-4.3.json` 与 `images/` 的相对目录。
2. 在 **Spine PRO 4.3.23** 中选择“导入数据”，导入根目录 **`bird112-4.3.json`**，缩放填写 **1**。图片路径为 `./images/`。
3. 保存为自己的 `.spine` 工程。本包提供可编辑 JSON，不伪造二进制 `.spine` 文件。
4. 动画模式中，`stand`、`move`、`attack` 打开循环；`hit` 播放一次，`dead` 播放一次并保持最后一帧。

需要 Professional 的加权网格功能。原始的 `bqiqi01` 等附件名称保持不变，避免贴图引用失效。

| 动作 | 时长 | 内容 |
| --- | --- | --- |
| `stand` | 2.4 秒 | 空中待机，慢振翅、呼吸、身体轻浮动，尾巴与背鳍延迟摆动 |
| `move` | 0.8 秒 | 原地飞行，大幅快速振翅、身体稍前倾，翼尖弹性跟随 |
| `attack` | 0.8 秒 | 持续原地俯冲，头低尾高、双翼收拢，小幅压翼与回弹 |
| `hit` | 0.5 秒 | 身体后震、张翼卸力、颚部摆动后复位 |
| `dead` | 1.6 秒 | 失衡下落、收翼落地、颚部收拢与短促回弹，末尾静止 |

## 俯冲循环与游戏接入

素材朝左。`attack` 中躯干保持约 **32–40°** 的向下俯冲倾角，双翼展幅收缩，头部低于身体、尾部抬高。**循环首尾都是俯冲姿态**，不会每圈恢复水平、重新蓄力，适合持续俯冲状态。循环内部用压翼、回弹和尾部延迟表现气流与速度感。

从 `stand` 或 `move` 切换到 `attack`，推荐设置约 **0.12–0.18 秒混合**，自然进入俯冲；退出时同样短混合。不要在每个循环结束时先切回待机。

`stand`、`move`、`attack` 的 **根骨骼位置始终为 0,0**。这是原地表演，身体轻浮动在 `hover` 子骨骼上，不会让角色在世界中向前或向下飞走。飞行速度、俯冲路径、追踪、碰撞和伤害由游戏控制。`dive_contact` 是可供参考的接触点骨骼，当前没有在每个循环里自动发送伤害事件。

`hit` 在 0.1 秒有 `impact` 事件，`dead` 在 1.4 秒有 `death_end` 事件。死亡动作包含高度下降，落地后保持，不能作为飞行循环使用。
