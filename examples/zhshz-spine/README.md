# ZHSHZ 菌冠感染者 · Spine PRO 4.3.23

基于上传的 Photoshop JSON 与 14 张角色透明 PNG，制作六个角色动作和一个独立毒液骨架。动作采用明显的预备、快速冲击、回弹与延迟跟随；移动原地循环，保留原图，不补绘未知的遮挡部位。

## 在本地 Spine 导入

1. 完整解压 ZIP，保留 JSON 与 `images/` 的相对目录。
2. 在 **Spine PRO 4.3.23** 中选择“导入数据”，导入 **`zhshz-4.3.json`**，缩放填写 **1**。图片路径为 `./images/`。
3. 保存为自己的 `.spine` 工程。本包提供可编辑 JSON，并不伪造 `.spine` 二进制工程。
4. 在另一个新工程中，以缩放 **1** 导入 **`poison-bullet-4.3.json`**。它包含独立的 `bullet` 动作。
5. 动画模式中查看动作。`stand`、`move`、子弹 `bullet` 循环播放；攻击与受击播放一次，死亡保持最后一帧。

使用 Professional 的加权网格功能。角色有 21 根骨骼、16 个插槽：原始 14 层，另加红色抓痕与喷吐效果。躯干和菌冠采用加权网格，四肢沿原始拆层关节旋转。菌冠具有延迟摆动，原始身体、手脚、服装与菌冠贴图字节不变。

| 动作 | 时长 | 内容 |
| --- | --- | --- |
| `stand` | 2.4 秒 | 呼吸、手臂轻摆、菌冠延迟晃动 |
| `move` | 1.0 秒 | 原地迈步、交替抬脚、身体前倾与双臂摆动 |
| `hit` | 0.5 秒 | 躯干后震、头部延迟与回弹 |
| `dead` | 1.6 秒 | 屈膝卸力、侧倒、菌冠触地与最终保持 |
| `attack_1` | 1.2 秒 | 前景手臂后收蓄力、前伸抓击、下扣回弹，红色三道抓痕 |
| `attack_2` | 1.4 秒 | 身体后仰与胸部蓄力、头部前送喷吐、菌冠回弹 |
| 子弹 `bullet` | 0.6 秒 | 一团飞行中的毒液在原地弹性形变，尾部摆动 |

## 事件与游戏接入

素材面向左侧。近战在 **0.5 秒**发送 `claw_hit` 事件，字符串为 `front_arm_paw`。红色抓痕在 0.5 秒出现，随后渐隐，0.8 秒隐藏。抓痕是独立 RGBA 程序生成特效，使用 additive 混合。

喷吐在 **0.5 秒**发送 `spawn_bullet` 事件，字符串为 **`projectile_spawn`**。收到事件时，在此骨骼的世界位置实例化独立毒液骨架并循环播放 `bullet`。角色的 `mouth` 骨骼表示喷吐出口，短喷流与该出口绑定，0.5–0.7 秒显示。现有整张头部没有独立下颌贴图，因此用头部前送和倾斜表现喷吐，不声称恢复或重建了嘴内结构。

`projectile_spawn` 的设置位置在嘴前方 120 像素，随头部运动。独立毒液美术本身朝左；接入时应把“素材左向”与游戏自己的正方向统一，避免多旋转 180°。可用 `mouth` 的世界方向为参考，扣除美术本身的左向 180°后应用方向差。人物镜像时同步处理子弹朝向。

**毒液 `bullet` 的根骨骼始终不发生位移。** 这是一团飞行中的毒液原地循环，不是固定距离的飞行轨迹。游戏负责子弹速度、世界位移、碰撞、伤害和销毁。人物 `move` 的根节点也始终为零位移；攻击中的身体前送是骨骼表演，不会推动游戏角色根节点。

本包不是已经导出的游戏 atlas。请在自己的 Spine 中导入、保存工程，再按游戏运行时版本导出 JSON/二进制与图集。使用 additive 抓痕时注意图集 PMA 与运行时混合设置一致。

## 预览与文件

- `preview.html`：普通尺寸和手机尺寸 GIF、关键姿势、绑骨图、独立毒液循环。可以直接用普通浏览器打开。
- 若本机限制本地文件资源，可在本目录运行 `python -m http.server 8000`，打开 `http://127.0.0.1:8000/preview.html`。
- 预览是独立软件渲染，**不是 Spine 桌面截图**。攻击 GIF 为查看方便重复演示，游戏中仍应一次播放。
- `images/*.png`：14 张原始角色图；SHA256 清单位于 `source/image-sha256.json`。
- `images/fx/claw_fx.png`、`spit_fx.png`：新增程序生成的透明抓痕和短喷流，不修改身体图。
- `images/fx/poison-flight.png`：复用本仓库 ZSX 包先前 AI 生成的透明毒液贴图；本次增加角色喷吐绑定和独立循环接入，未把复用贴图标称为本次新生成美术。来源及 SHA256 在 `source/projectile-image.json`。
- `source/photoshop.json`：保留上传图层坐标和图层顺序，仅规范化图片路径。
- `rig-config.json`：关节、绑定、脚步与事件配置。
- `runtime-validation.json`、`bullet-runtime-validation.json`：官方运行库逐帧记录。
