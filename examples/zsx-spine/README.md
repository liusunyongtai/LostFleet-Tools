# ZSX · 近战、喷吐与独立毒液子弹

目标 **Spine PRO 4.3.23**。角色有 26 根可编辑骨骼、5 个网格插槽（含短暂口液效果）；独立毒液子弹有 3 根骨骼、1 个网格。

四张角色原始透明 PNG 字节保持不变，PS 初始组装位置与层顺序保留，根骨骼移至脚下。新增的 `images/fx/poison-flight.png` 是本次生成的透明毒液贴图，来源与哈希记录在 `source/projectile-image.json`，不是从角色原图中补出的隐藏部件。

## 在本地 Spine 导入

1. 完整解压 ZIP，保留两个 JSON 与 `images/` 的相对目录。
2. 在 Spine PRO 4.3.23 中选择“导入数据”，导入 **zsx-4.3.json**，缩放设为 **1**，作为角色工程。
3. 另建工程，用同样方式导入 **poison-bullet-4.3.json**，缩放设为 **1**，作为毒液子弹工程。
4. 若图片丢失，将两个骨骼的图片路径都指向包内 `images/`。
5. 导入后分别“另存为”自己的 `.spine` 工程。游戏所需的 atlas、纹理和运行时数据请由本地 Spine 导出。

本包提供可编辑 Spine JSON，不包含原生 `.spine` 文件或已打包图集。`source/photoshop.json` 是原始 PS 摆位备份，不是动画成品。

## 角色动作

| 名称 | 时长 | 播放方式 | 设计 |
|---|---:|---|---|
| stand | 2.4 秒 | 循环 | 鼓腹呼吸、头部轻摆、下颌和长舌跟随 |
| dead | 1.6 秒 | 单次，保持末帧 | 屈膝失力、侧倒、腹部卸力、舌部收拢和落地回弹 |
| hit | 0.5 秒 | 单次 | 后震、腹部轻微挤压、头颈和手臂延迟回弹 |
| attack_1 | 1.2 秒 | 单次 | 后缩蓄力、前扑抓击、手臂前伸、回弹收势 |
| attack_2 | 1.4 秒 | 单次 | 鼓腹吸气、头部后仰、压腹前送喷吐、余势回弹 |
| move | 1.0 秒 | 循环 | 双腿交替、重心起伏、摆臂和舌部跟随；根骨骼保持原地 |

近战使用前景爪臂，发力时有少量弹性伸展以突出小尺寸轮廓。躯干、腹部和双腿仍使用原来的一张连续 PNG，通过加权网格处理，不切断腿部，也没有恢复被遮挡的肢体。

头部原图为张嘴姿态，下颌和舌部只做有限幅度的网格形变，没有新增闭嘴或隐藏牙齿贴图。喷吐强调吸气时腹部膨起、出液时压腹与头颈前送。预览按统一比例绘制，导入的坐标单位仍与原图一致。

## 独立毒液子弹

`poison-bullet-4.3.json` 只有一个动画：**bullet**，时长 **0.6 秒**，用于循环播放。

- 一团朝画面左方飞行的黏稠毒液，带气泡、高光与两条相连的拖尾。
- 团块伸缩、拖尾轻摆，首尾无缝；**根骨骼始终为零位移，没有烘焙水平或竖直飞行轨迹**。
- 实际速度、弧线、朝向、碰撞和销毁由游戏代码控制。
- 子弹画布为 360×180 个原图坐标单位，角色与子弹应使用一致的导入缩放。原图 PNG 是高分辨率透明贴图，Spine 中按上述尺寸使用。
- 右向飞行可由游戏翻转子弹，保留同一个 `bullet` 循环，不需要另做向右飞行位移。

## 喷吐事件与衔接

- `attack_1` 在 **0.5 秒（30fps 第 15 帧）**发送 `melee_hit`，字符串为 `melee_tip`。此骨骼提供前景爪端参考，伤害结算由游戏实现。
- `attack_2` 在 **0.5 秒（第 15 帧）**发送 `spawn_bullet`，字符串为 **projectile_spawn**。
- 接收 `spawn_bullet` 后，在 `projectile_spawn` 世界坐标创建独立子弹，播放 `bullet` 循环，再由游戏施加位移。该位置已按毒液贴图长度前置，使拖尾接近嘴部。
- `mouth` 骨骼的本地 +X 是喷吐方向；毒液源图默认朝左。若直接沿 `projectile_spawn` 的旋转放置子弹，飞行方向取其本地 **−X**。
- 角色里的 `spit_fx` 是 0.5–0.7 秒的短暂口液示意，尾端在效果生长时保持对齐嘴部。**若游戏另行生成独立子弹，可隐藏 `spit_fx` 插槽，避免重复显示同一团毒液。**
- `hit` 在 0.1 秒发送 `impact`；`dead` 在 1.4 秒发送 `death_end`，到 1.6 秒保持末帧。
- `move` 在 0.5 秒和 1.0 秒发送 `footstep`，字符串区分 `back_leg` / `front_leg`。实际移动由游戏控制。

待机、移动、子弹可循环；攻击、受击和死亡应单次播放。GIF 中攻击的循环仅供反复查看。

## 查看与复现

直接打开 `preview.html` 可查看六组角色普通尺寸及约 128px 角色高度的动图、独立子弹动图、透明毒液贴图、关键姿势和骨骼图。预览由独立软件渲染器生成，不是 Spine 桌面截图。

完整源码仓库提供生成器、配置与测试；可以修改枢轴、权重和动作控制点后运行：

```sh
python tools/build_zsx_spine.py
SPINE_CORE_MODULE=/path/to/@esotericsoftware/spine-core/dist/index.js node tests/validate_zsx43.mjs
python -m unittest discover -s tests -v
```

生成器会复用包内毒液 PNG，不需要重新生成图片。独立 ZIP 可直接导入 Spine，无须运行生成器，也没有更改角色拆分网页、PNG 导出或 ZIP API。

## 验证范围

官方 `@esotericsoftware/spine-core 4.3.13` 已读取两个目标版本 4.3.23 骨骼，以 **60Hz 检查角色 492 个姿势、子弹 37 个姿势**。所有可见网格顶点均检查为有限值，并与独立预览计算比较骨骼矩阵、抽样网格顶点、附件显隐和绘制顺序。记录分别在 `runtime-validation.json`、`bullet-runtime-validation.json`。

自动化测试还检查原始 PNG 哈希与 Alpha、PS 原始摆位、权重归一、角色循环及复位、脚部路径、躯干与头部连通性、近战前伸、鼓腹压腹、出液时刻、口液尾端对齐、倒地接地、预览统一缩放，以及子弹透明背景、独立根骨骼零位移、首尾画面一致、团块形变和连通性。
