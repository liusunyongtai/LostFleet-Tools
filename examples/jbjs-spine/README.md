# JBJS · 单臂前抓骨骼动画

目标 **Spine PRO 4.3.23**，15 根可编辑骨骼、8 个加权网格。八张原始透明 PNG 字节保持不变，保留 PS 初始摆位和图层顺序，根骨骼移至脚下。只驱动素材中已有的完整手臂，不补画缺失的另一只手。

## 本地 Spine 导入

1. 完整解压 ZIP，保留 JSON 和 `images/` 的相对目录。
2. 在 Spine PRO 4.3.23 中选择“导入数据”，选择 **jbjs-4.3.json**，缩放设为 **1**。
3. 若图片丢失，将骨骼图片路径指向解压目录的 `images/`。
4. 在动画模式选择下面的动作，再“另存为”自己的 `.spine` 项目。图集、纹理和游戏运行时数据请由本地 Spine 导出。

本包提供可编辑 Spine JSON，不包含原生 `.spine` 工程或已打包的 atlas。`source/photoshop.json` 是原始 PS 摆位备份，不是动画成品。

| 动作名 | 时长 | 播放方式 | 设计 |
|---|---:|---|---|
| stand | 2.4 秒 | 循环 | 躯干呼吸、大头摆动、手腕延迟和轻微屈膝 |
| dead | 1.6 秒 | 单次，保持末帧 | 膝部失力、身体前侧倒、落地回弹、最终稳定 |
| hit | 0.5 秒 | 单次 | 后震、头颈延迟、单臂甩动和回弹复位 |
| attack | 1.2 秒 | 单次 | 后收蓄力、单手向左前伸抓击、手腕下扣、带回与收势 |
| move | 1.0 秒 | 循环 | 双腿交替、重心起伏、单臂摆动，根骨骼保持原地 |

角色朝画面左侧。抓击使用 `zuogebo`、`zuoshoubi`、`zuoshou` 三张原图，依次绑定上臂、前臂和手掌，保留原来张开的爪形手指。手掌没有单独切出手指骨骼，不声称生成了新的握拳或指节贴图。另一侧残臂仍在原躯干图层中，保持原有形态。

动作强调准备、快速前伸、延迟回弹和跟随。攻击时头部稍后收，让爪部轮廓清楚，手臂暂时移至躯干和头部前方绘制；收势后恢复 PS 原始绘制顺序。双腿通过连续网格弯曲、脚部反向补偿，不将膝盖切成两张图，也没有生成被衣物遮挡的腿部。

## 游戏事件与位移

- `attack` 在 **0.5 秒（30fps 第 15 帧）**发送 `claw_hit`，事件字符串指向 `claw_tip` 参考骨骼。请由游戏逻辑进行碰撞检测和伤害结算。
- `hit` 在 0.1 秒发送 `impact`。
- `dead` 在 1.4 秒发送 `death_end`，到 1.6 秒保持稳定倒地姿势。
- `move` 在 0.5 秒和 1.0 秒发送 `footstep`，字符串区分 `back_leg` / `front_leg`。
- 移动是原地循环，实际水平位移由游戏代码控制。待机与移动循环播放；抓击、受击和死亡应单次播放。

后脚与前脚沿用 PS 摆位中的高度差，不强行将原图的透视脚底改成同一高度。

## 预览和复现

直接打开 `preview.html` 查看五组普通尺寸、约 128px 角色高度的 GIF，以及关键姿势和骨骼图。手机尺寸 GIF 为便于比较均循环演示。预览来自独立软件渲染器，不是 Spine 桌面截图。

完整源码仓库包含生成器和测试，可以修改 `rig-config.json` 的枢轴、绑定与肢体链，或修改 `tools/build_jbjs_spine.py` 的动作控制点后运行：

```sh
python tools/build_jbjs_spine.py
SPINE_CORE_MODULE=/path/to/@esotericsoftware/spine-core/dist/index.js node tests/validate_jbjs43.mjs
python -m unittest discover -s tests -v
```

独立 ZIP 可直接导入 Spine，无须运行生成器。生成器复用现有 Pillow、OpenCV、NumPy 渲染工具；没有修改角色拆分网页、PNG 导出或 ZIP API。

## 验证范围

使用官方 `@esotericsoftware/spine-core 4.3.13` 读取目标版本 4.3.23 数据，以 **60Hz 验证五个动作共 407 个姿势**，检查所有网格顶点为有限值，并与独立预览数学计算比较骨骼矩阵、抽样网格坐标和临时绘制顺序。记录见 `runtime-validation.json`。

自动化测试还覆盖八张 PNG 哈希与 Alpha、PS 初始摆位、权重归一、循环首尾、原地根骨骼、双脚运动路径、膝部网格连通、单手抓击前后幅度和下带、旋转不突跳、攻击和受击复位、倒地接地与末帧稳定性。
