# SJT · 机械右臂前戳与举臂下砸

面向 **Spine PRO 4.3.23**，17 根可编辑骨骼、8 个加权网格。保留提供的八张原始透明 PNG、PS 初始摆位和图层顺序，根骨骼移至脚下；没有补画隐藏部位或生成额外武器图层。

## 在本地 Spine 导入

1. 完整解压 ZIP，保留 JSON 与 `images/` 的相对目录。
2. 在 Spine PRO 4.3.23 中选择“导入数据”，选择 **sjt-4.3.json**，缩放设为 **1**。
3. 如果图片丢失，将骨骼图片路径指向解压目录的 `images/`。
4. 进入动画模式选择下列动作，再“另存为”自己的 `.spine` 工程。游戏所需的 atlas、纹理和运行时数据请通过本地 Spine 导出。

本包是可编辑 Spine JSON，不包含原生 `.spine` 文件或已打包图集。`source/photoshop.json` 是原始 PS 摆位备份，不是动画成品。

| 动作名 | 时长 | 播放方式 | 设计 |
|---|---:|---|---|
| stand | 2.4 秒 | 循环 | 沉重呼吸、头部轻摆、重心和双臂跟随 |
| dead | 1.6 秒 | 单次，保持末帧 | 膝部失力、向侧前方倒下、机械臂卸力、落地回弹并稳定 |
| hit | 0.5 秒 | 单次 | 身体后震、头颈延迟、双臂跟随和回弹复位 |
| attack_1 | 1.2 秒 | 单次 | 右臂后收蓄力、向左前方横向戳击、活塞伸出、回收收势 |
| attack_2 | 1.4 秒 | 单次 | 举起右臂超过头部、停顿蓄力、快速向脚前下砸、身体下压与回弹 |
| move | 1.0 秒 | 循环 | 双腿交替重步、屈膝起伏、左臂摆动、重机械臂轻度反摆，根骨骼保持原地 |

攻击均由原 `youshoubi` 机械右臂完成，目标方向为画面左前方。左臂只做平衡和惯性跟随，不作为第二个攻击部件。

## 机械臂与动作细节

右臂原图是一整块机械结构。上、下外壳按刚性区域绑定，伸缩集中在中部连接段；前戳时活塞向前伸出约 50 个原图像素。机械臂经过最低点及收回时，会先缩短连接段，避免长臂扫进地面。没有把钢壳弯成柔软肢体，也没有生成不可见的背面结构。

下砸动作在 0.3–0.4 秒举臂停顿，约 0.633 秒落砸；回弹后机械肩轴沿连续角度收回。该动作的右肩旋转最终累计到 360°，与初始画面姿态相同，避免相邻关键帧突然从大角度跳到零度。收势后的可见骨骼恢复初始姿态。

宽裤腿使用较宽的膝部权重过渡，鞋子单独绑定脚部，保留原始透明边缘和脚掌形状，不切断裤腿来拼接步行。移动完全原地循环，实际角色位移由游戏代码控制。

## 游戏事件

- `attack_1`：**0.5 秒（30fps 第 15 帧）**发送 `poke_hit`。
- `attack_2`：**19/30 秒，约 0.633 秒（第 19 帧）**发送 `slam_hit`。
- 两个命中事件的字符串均指向 `tool_tip` 骨骼，可作为命中位置参考；真实碰撞、伤害和地面检测由游戏逻辑处理。
- `hit` 在 0.1 秒发送 `impact`。
- `dead` 在 1.4 秒发送 `death_end`，到 1.6 秒保持稳定末帧。
- `move` 在 0.5 秒和 1.0 秒发送 `footstep`，字符串区分 `back_leg` / `front_leg`。

待机和移动可循环播放；两个攻击、受击和死亡应单次播放。动图中攻击循环仅用于反复查看。

## 查看与复现

直接打开 `preview.html` 查看六组普通尺寸和约 128px 角色高度的 GIF，以及关键姿势和骨骼图。手机 GIF 为便于比较均循环演示。预览由独立软件渲染器生成，不是 Spine 桌面截图。

完整源码仓库包含 `tools/build_sjt_spine.py`、`rig-config.json` 和测试。可调整枢轴、肢体链或动作控制点后运行：

```sh
python tools/build_sjt_spine.py
SPINE_CORE_MODULE=/path/to/@esotericsoftware/spine-core/dist/index.js node tests/validate_sjt43.mjs
python -m unittest discover -s tests -v
```

独立 ZIP 可直接导入 Spine，无须运行生成器。生成器复用现有 Pillow、OpenCV、NumPy 工具；没有修改角色拆分网页、PNG 导出或 ZIP API。
